SpaceRanger  (pre-release)
==========================

A native PC port of Toy Story 2: Buzz Lightyear to the Rescue (N64), made by
statically recompiling the original game with N64Recomp and rendering it with
RT64. Unofficial fan project; no game data is included. Built with help
from AI coding assistants (Anthropic's Claude, and OpenAI's ChatGPT/Codex).

You need your own copy of the game
----------------------------------
Supported ROM: Toy Story 2 (N64, USA). .z64, .n64 and .v64 dumps all work.

First launch
------------
1. Run SpaceRanger.exe.
2. On the title screen choose "Load ROM" and select your ROM. It is checked
   and copied into the "spaceranger-config" folder next to the exe, so you
   only do this once. (You can also put the ROM next to SpaceRanger.exe and
   it is found automatically.)
3. Choose "Start Game".

Settings and saves live in "spaceranger-config". Delete that folder to start
fresh (you will be asked for the ROM again).
